The goal of this script is:
1) To collect the user's desired exoskeleton torque magnitude from several options (0% to max torque magnitude) to command the mid-level controller
3) To display user's current earnings as a real-time plotting time-series

The GUI provides users with 10 options for a control setting (torque profile). Options range from 0Nm, 7.8Nm-22.8Nm in 1.5Nm increments

While closing the window for gRPC use control c instead of control z
